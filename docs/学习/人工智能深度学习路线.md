# 人工智能深度学习路线

这篇路线不是“把所有知识点都列一遍”，而是尽量回答两个更实际的问题：

1. 我应该先学什么，后学什么？
2. 学到什么程度，才算真的入门了？

如果用一句话概括：

**深度学习不是先背模型名字，而是先补基础，再做小项目，再选方向深入。**

---

## 1. 先搞清楚：你要学的到底是什么

很多人一开始会把下面这些词混在一起：

- 人工智能（AI）
- 机器学习（Machine Learning）
- 深度学习（Deep Learning）
- 大模型（LLM）

最简单的理解是：

- **人工智能**：大范围概念，目标是让机器表现出“像智能”的能力
- **机器学习**：人工智能里的一大类方法，让机器从数据中学规律
- **深度学习**：机器学习里的一大类方法，核心是神经网络
- **大模型**：深度学习发展到最近几年后，非常重要的一类实际应用

所以学习顺序通常不是：

`一上来就学大模型`

而是：

`Python -> 数学基础 -> 机器学习基础 -> 神经网络基础 -> 深度学习实战 -> 选方向深入`

---

## 2. 学之前先定目标

不同目标，路线不一样。

### 目标 A：想入门，能看懂教程和论文里的常见术语

重点：

- Python
- 线性代数和概率基础
- 机器学习基础概念
- 神经网络前向传播和反向传播
- 用 PyTorch 跑通简单项目

### 目标 B：想找工作，做算法/AI 工程方向

重点：

- 基础理论更扎实
- 熟悉 PyTorch
- 做过 2 到 4 个完整项目
- 会数据处理、训练、评估、调参、部署
- 至少有一个方向能说清楚

### 目标 C：想做大模型应用开发

重点：

- 不必一开始钻太深的数学证明
- 先会深度学习基础和 Transformer
- 重点补工程能力：数据、推理、微调、评测、RAG、部署

如果你现在还不确定，先按 **目标 A + C 的混合路线** 学，最实用。

---

## 3. 推荐的整体路线

可以把学习过程拆成 5 个阶段。

### 第 0 阶段：工具准备

先把这些东西用顺手：

- Python
- `numpy`
- `pandas`
- `matplotlib`
- Jupyter Notebook
- Git
- 基本 Linux / 命令行

做到什么程度算过关：

- 会写函数、类、循环、列表推导式
- 会读写 CSV / JSON
- 会做基础数据清洗
- 会画折线图、柱状图
- 会用虚拟环境
- 会 `git clone`、`git add`、`git commit`

如果这一关没过，后面学深度学习会很痛苦。

### 第 1 阶段：补机器学习和数学基础

这一阶段不要求你变成数学系学生，但有些东西必须懂。

最重要的数学：

- 线性代数
  - 向量、矩阵
  - 矩阵乘法
  - 转置
  - 维度变化
- 概率统计
  - 概率
  - 条件概率
  - 均值、方差
  - 分布的基本直觉
- 微积分
  - 导数
  - 链式法则
  - 偏导数
  - 梯度下降的直觉

最重要的机器学习概念：

- 训练集、验证集、测试集
- 特征和标签
- 欠拟合、过拟合
- 损失函数
- 优化器
- 学习率
- 正则化
- 分类和回归

建议这一阶段顺手了解这些传统模型：

- 线性回归
- 逻辑回归
- 决策树
- 随机森林
- SVM

不是因为它们比深度学习更“先进”，而是因为它们能帮你建立最基本的建模直觉。

### 第 2 阶段：神经网络基础

这是正式进入深度学习的门槛。

你需要真正理解：

- 什么是神经元
- 什么是多层感知机（MLP）
- 前向传播
- 反向传播
- 激活函数
- 损失函数
- 梯度下降和优化器
- Batch / Epoch

常见必须掌握的概念：

- `ReLU`
- `Sigmoid`
- `Softmax`
- `Cross Entropy`
- `MSE`
- `SGD`
- `Adam`
- Dropout
- Batch Normalization

做到什么程度算过关：

- 能自己用 PyTorch 写一个简单的分类模型
- 能解释训练损失下降代表什么
- 能看懂模型输入输出维度
- 知道为什么会过拟合

### 第 3 阶段：主流深度学习模型

这一阶段开始接触“模型家族”。

#### 图像方向先学什么

- CNN
- 卷积、池化、特征图
- 常见网络：LeNet、AlexNet、ResNet

适合任务：

- 图片分类
- 目标检测
- 图像分割

#### 序列和文本方向先学什么

- RNN
- LSTM / GRU
- Attention
- Transformer

适合任务：

- 文本分类
- 情感分析
- 翻译
- 问答
- 大模型

#### 现在最值得投入的重点

如果你时间有限，建议：

1. 神经网络基础
2. CNN 基础
3. Transformer 基础
4. PyTorch 实战

RNN/LSTM 了解即可，不必花太久。

### 第 4 阶段：选一个方向做项目

真正拉开差距的不是“看了多少视频”，而是你有没有做过完整项目。

比较常见的方向：

- 计算机视觉（CV）
- 自然语言处理（NLP）
- 推荐系统
- 语音
- 大模型应用

如果你是新手，建议优先选下面两个之一：

- **图像分类**
- **文本分类**

因为这两个方向最容易做出第一个完整闭环。

### 第 5 阶段：工程化和深入

到了这一步，你已经不是“只会跟教程敲”了。

接下来要补的是：

- 数据集管理
- 实验记录
- 模型评估
- 调参方法
- GPU 训练
- 推理优化
- 模型部署
- 模型监控

如果你走大模型方向，还要补：

- Tokenizer
- Embedding
- Self-Attention
- Transformer 结构
- 预训练 / 微调
- LoRA / QLoRA
- RAG
- 向量数据库
- 推理服务

## 4. 一条更适合新手的时间路线

下面是一条比较务实的路线，假设你每周能投入 8 到 12 小时。

### 第 1 个月：补 Python + 数学直觉 + 机器学习基础

目标：

- Python 基本熟练
- 看懂监督学习基本概念
- 明白损失函数、训练集、验证集、过拟合

建议输出：

- 一个 `numpy` 小练习
- 一个用 `scikit-learn` 做的分类项目

### 第 2 个月：神经网络基础 + PyTorch 入门

目标：

- 能用 PyTorch 写一个简单 MLP
- 知道训练循环怎么写
- 会看 loss / accuracy

建议输出：

- 手写数字识别
- 二分类或多分类小项目

### 第 3 个月：CNN 或 NLP 基础

目标：

- 至少掌握一个方向的典型模型
- 会处理真实一点的数据

建议输出二选一：

- 图像分类项目
- 文本分类项目

### 第 4 个月：Transformer 基础

目标：

- 知道 Attention 在做什么
- 能解释 Transformer 为什么重要
- 能用现成库完成简单文本任务

建议输出：

- 用 Hugging Face 跑一个文本分类或摘要任务

### 第 5 到 6 个月：做一个完整作品

目标：

- 有一个可以展示的项目
- 能讲清楚任务、数据、模型、指标、问题和改进

建议项目：

- 垃圾图片分类
- 商品评论情感分析
- 新闻分类
- 简单问答机器人
- 基于知识库的 RAG Demo

## 5. 每个阶段应该学到什么程度

很多人最大的问题不是不努力，而是不知道“学到哪里算够”。

### Python 阶段

够用标准：

- 能独立写 200 行左右的小程序
- 能读别人的基础代码
- 会调试报错

### 数学阶段

够用标准：

- 能看懂向量和矩阵维度
- 知道导数在优化里是干什么的
- 看见损失函数不会完全发懵

### 机器学习阶段

够用标准：

- 知道完整训练流程
- 知道分类指标和回归指标的区别
- 知道为什么要分训练集和测试集

### 深度学习阶段

够用标准：

- 能独立搭一个 PyTorch 模型
- 能跑训练和验证
- 能判断模型是否明显过拟合

### 项目阶段

够用标准：

- 能把项目讲清楚
- 能复现实验
- 能写 README
- 能说出下一步优化方向

## 6. 新手最容易踩的坑

### 坑 1：一上来就学大模型微调

这会让你表面上学得很“新”，实际上底层全是空的。

更稳的顺序是：

- 先懂神经网络基础
- 再懂 Transformer
- 再碰大模型应用和微调

### 坑 2：只看课，不做项目

深度学习不是只靠听懂就能会的。

你必须亲手做过这些事：

- 读数据
- 清洗数据
- 写训练循环
- 看训练曲线
- 调学习率
- 查过拟合

### 坑 3：数学焦虑太重

很多人因为“数学还没学完”就不敢开始做项目。

更现实的方式是：

- 数学补到够用
- 一边做项目一边回头补

不要等到“全懂了”再开始，那样很可能一直开始不了。

### 坑 4：模型名字背得很多，训练一个都没跑通

如果你还没自己跑通过一个完整分类项目，那你现在最需要的不是继续看模型综述，而是先把第一个项目做完。

### 坑 5：只会调库，不知道为什么

只会调用现成 API 没问题，但至少要知道：

- 输入是什么
- 输出是什么
- 损失怎么算
- 指标代表什么

否则项目一出问题，你就很难排查。

## 7. 推荐的实战顺序

如果你想把路线压得更短，建议按这个顺序做项目：

1. `scikit-learn` 做一个表格数据分类
2. PyTorch 做一个手写数字识别
3. PyTorch 做一个图片分类
4. Hugging Face 做一个文本分类
5. 做一个自己的小型端到端项目

这个顺序的好处是：

- 难度递增比较平滑
- 能快速建立信心
- 每一步都能看见成果

## 8. 大模型时代还要不要学传统深度学习

要，而且很有必要。

原因很简单：

### 1. 不学基础，你很难真正理解大模型

比如这些概念：

- Embedding
- Attention
- 梯度下降
- 训练和推理
- 微调

本质上都还是深度学习体系里的东西。

### 2. 你会更容易定位问题

当模型效果差时，你至少知道该先看：

- 数据问题
- 标签问题
- 损失函数
- 过拟合
- 学习率
- 输入长度

### 3. 工程岗位不只做“调接口”

真实工作里，很多场景需要你：

- 评估模型
- 处理数据
- 设计实验
- 优化推理
- 看训练日志

这些都绕不开深度学习基础。

## 10. 如果你现在就开始，第一周该做什么

你可以直接照着做：

### Day 1

- 装 Python
- 装 `numpy`、`pandas`、`matplotlib`、`scikit-learn`
- 配好 Jupyter

### Day 2

- 复习 Python 基础
- 写 2 到 3 个数组和数据处理小练习

### Day 3

- 学监督学习、训练集、验证集、测试集
- 用 `scikit-learn` 跑一个最简单的分类任务

### Day 4

- 学神经网络、激活函数、损失函数
- 看懂一个最简单的 MLP 示例

### Day 5

- 用 PyTorch 跑通一个最小分类例子

### Day 6

- 记录你遇到的问题
- 整理一份自己的学习笔记

### Day 7

- 回顾一周内容
- 写出下一周计划

如果你第一周能做到这里，路线就已经走对了。

---

## 11. 最后给一个简单判断标准

如果你已经能做到下面这些事，就算真正跨过“入门线”了：

- 能解释机器学习和深度学习的区别
- 能用 PyTorch 搭一个简单模型
- 能独立跑通一个分类项目
- 能看懂 loss 和 accuracy 的基本变化
- 能说出一个项目为什么效果不好

做到这一步之后，再去学：

- Transformer
- 大模型微调
- RAG
- 多模态
- Agent

会稳很多。

---

## 12. 一句话总结

**深度学习最靠谱的学习方式，不是先追最新名词，而是先打基础，再做项目，再选方向深挖。**
