# 文档目录

`docs/` 按日常最常用的场景拆成 4 类：

- `ai/`
  - AI 工具、智能体、提示词工作流、自动化实践
- `学习/`
  - 学习笔记、阅读摘录、实验记录、练习材料
- `项目/`
  - 需求说明、设计方案、里程碑、发布说明、复盘
- `规范/`
  - 团队约定、模板、流程、检查清单

当前推荐的放置方式：

- 和 AI 工具本身有关的教程，放到 `docs/ai/`
- 和个人或团队积累有关的内容，放到 `docs/学习/`
- 和某个具体项目交付物有关的内容，放到 `docs/项目/`
- 和协作规则、模板、检查清单有关的内容，放到 `docs/规范/`
